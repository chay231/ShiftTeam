# 🚗 ShiftTeam: Интерактивный веб-помощник по ремонту автомобилей

**ShiftTeam** — это кроссплатформенная краудсорсинговая веб-платформа, созданная для упрощения самостоятельного технического обслуживания и ремонта автомобилей. 

Главная особенность проекта — **комбинированный подход к визуализации**. Основная база руководств построена на легких и понятных 2D-схемах, а для критически важных узлов интегрируются **обобщенные интерактивные 3D-элементы**, которые можно вращать и изучать прямо в браузере у капота в гараже.

---

## ⚙️ Стек технологий

* **Backend:** C# / ASP.NET Core Web API
* **Frontend:** React, JavaScript
* **3D-моделирование:** Blender
* **DevOps & Инфраструктура:** Docker, NGINX, PostgreSQL
